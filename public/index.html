Jain Restaurants Finder
Add a restaurant to the directory. Only add places that serve some food without onion, garlic, potatoes, carrots, and other root vegetables. Submissions go straight into the live directory — the agent checks its own work first and refuses listings it cannot verify.

How it works

  1. Click + Add Restaurant and enter the name and city.
  2. Check the preview — the agent shows what it found, including its own checks.
  3. If the preview looks right, submit it to the directory.
